{# The tender row on /app/my (a column of the funnel board or a folder). Context: row (MyTenderRow: tender_id / title / customer_name / deadline_at / tender_url / note / status / profile_id); the chrome — from the `t` catalog (the cabinet i18n), NOT to be confused with the row variable (previously the row was called `t` and shadowed the catalog — now `row`, so that `t.*` is available inside). The stage is labelled only inside a folder (`in_folder`): on the board the stage is the column itself, duplicating it on every row is noise. The urgency badge is the same color code as on the dashboard (expired / ≤2 days / ≤7 days); if there is no deadline — there is no badge, we do not invent anything. The customer / the note are data, “as is”, they are not translated by the interface language. The heading (#464 defect class): profile_id is resolved by a subquery to delivery_outbox (workflow_service._PROFILE_RESOLVE_SQL) — when it exists, we draw the same translation toggle as in the feed / agenda, and the link leads INSIDE the product (the cabinet card), not to eNabavke. ‼️ view is NOT "feed": the view "feed" in GET /app/tenders/{id}/title (routes_tender_ai.py) recomputes the link to data.source_url (the external one) — after the first click “Show translation” the row would lead off the portal, reproducing exactly the defect this fix repairs. ‼️ And NOT one common view for both columns: /app/my renders ONE tender in a funnel stage and in a folder AT THE SAME TIME (the same include, the same tender_id / profile_id) — a shared view would give the same DOM id to two rows (_card_title.html builds the id from view), and the hx-target of the second button would land in the first. "my_board" / "my_folder" (routes_tender_ai._CARD_TITLE_VIEWS) are the same markup / link, different ids; the switch is `in_folder`, which the calling template (my_tenders.html) already sets for the folders column. Without a profile_id (the tender does not resolve to any profile of the tenant) — we leave the external link without the toggle: a 404 is worse than an honest link to the portal (the project rules). #}
